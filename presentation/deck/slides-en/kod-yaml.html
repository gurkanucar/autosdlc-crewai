A short look at the code

Agents and tasks are
defined in YAML

config/agents.yaml (shortened)

review:
  role: Architecture Review Agent
  goal: Independently audit the design
    against the requirements.
  backstory: A senior architect who catches
    missing requirements before any
    code is written.

testing:
  role: Test Agent
  goal: Prepare API, UI and unit tests
    that match the requirements.

config/tasks.yaml (shortened)

review:
  description: |
    Project idea: $idea
    The design to review: $context
    Write the whole report in $language.
    Findings: | No | Severity | Finding |
    Critical or High finding → REVISE.
    The last line must be exactly
    "VERDICT: APPROVE" or "VERDICT: REVISE".
  expected_output: A review report
    with a findings table and a VERDICT line.

Prompts live apart from the code: adding or changing an agent needs no Python. The application fills the variables that start with $. Prompts are in English; $language chooses the document language.

In CrewAI an agent is defined by three things: its role, its goal and its backstory. A task says what to do and what output is expected. We keep them in YAML files. Note the review task: we ask the model to end with a verdict line that a program can read, because the next step is done by code.
