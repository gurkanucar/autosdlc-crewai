Error 3: the “İptal” button
is not found

tests/ui/registration.test.js (written by the Test Agent)

page.getByRole('button',
  { name: /iptal/i })

// the button on screen: "İptal"
// result: no match ✗

Why?

In JavaScript the /i flag does not match the Turkish “İ” (U+0130) with “i”.

The second trap

Python's re.I does match it, so our check written in Python did not see the error.

Fix

The build check imitates JavaScript and warns before the tests run.

AutoSDLC · SDLC with AI agents18 / 24

This error is specific to a Turkish UI. “İptal” means Cancel. The tests passed with the English UI but could not find the Cancel button in Turkish. When we first wrote the check, Python's regex behaved differently, so we did not catch it. Now we handle the letter İ explicitly.
