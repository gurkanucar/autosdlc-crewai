Appendix

“What was a US?”
terms

SDLC
Software Development Life Cycle: the stages from planning to maintenance.
agent
A software component driven by an LLM, with a role, a goal and tools.
LLM
Large Language Model: a model that generates text (e.g. GLM, Kimi).
CrewAI Flow
A Python structure that connects agents and steps in order.
FR / NFR
Functional / Non-Functional Requirement: what it does and how well.
US / AC
User Story and Acceptance Criteria.
traceability
Which design, file and test every requirement is linked to.
repair loop
After a failing test the code is fixed and the tests run again.
CR
Change Request: a change added to the project later.
delta mode
In a CR, only the affected stages run again.
reasoning budget
How many characters a model may think before it answers.
build check
Static checks for known mistakes, before the tests run.
