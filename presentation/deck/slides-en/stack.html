Technology

The technologies
we used

CrewAI Flows

Python framework that runs the agents and the order of the stages.

OpenCode Go

The model gateway. Default model glm-5.3-flash; each stage can use its own model.

Streamlit

Live UI: stage status, agent output, questions, document editing.

SQLite

Run history, events, versions and change requests.

Playwright + pytest

API and UI tests of the generated project, with a real Chromium.

Docker + Dokploy

How both AutoSDLC and the apps it generates are deployed.

AutoSDLC · SDLC with AI agents04 / 24

The generator is Python, but the projects it creates can be Node.js, Go, Rust or Python; web, CLI or desktop. The Docker image has all these toolchains, because the tests of the generated code run in the same container.
