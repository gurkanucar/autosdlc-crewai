crewai_engine.py · _ask() (simplified)

prompt = Template(task["description"]).substitute(
    idea=idea, context=context, language="English")

agent = Agent(role=cfg["role"], goal=cfg["goal"],
              backstory=cfg["backstory"], llm=llm,
              allow_delegation=False, max_iter=3)
task = Task(description=prompt, agent=agent,
            expected_output=task["expected_output"])
raw = Crew(agents=[agent], tasks=[task]).kickoff().raw

if raw.startswith("USER_QUESTION:"):
    raise ClarificationNeeded(...)  # a question in the UI

1. Prompt

The YAML template is filled with the idea, the context and the language.

2. Agent + Task + Crew

Every stage is a small crew with one agent. Delegation is off.

3. Model

The OpenCode Go gateway; each stage can use its own model.

4. Question

On USER_QUESTION: the run stops; the answer is added to the context.

AutoSDLC · SDLC with AI agents08 / 24

This function is the common entry point of every stage. It fills the prompt from YAML, builds the CrewAI Agent and Task and runs them. We turned delegation off: we wanted the routing to be explicit in the code, not agents handing work to each other. If the model notices a missing decision it returns a question in a fixed format, and we show it to the user in the UI.
