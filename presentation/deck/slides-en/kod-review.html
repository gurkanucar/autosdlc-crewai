runner.py · review() (shortened)

def review(self):
    for number in range(1, MAX_REVIEW_ROUNDS + 1):  # 2 rounds
        report = self._generate("review")
        if review_verdict(report) == "APPROVE":
            break
        # REVISE: the findings go to the Design Agent
        self.docs["design"] = self._generate("design",
            "ARCHITECTURE REVIEW FINDINGS — revise the "
            "existing design only where these findings "
            "require it:" + report,
            base=self.docs["design"])

Verdict line

The VERDICT (or Turkish KARAR) line is read with a regex.

The Design Agent runs again

It gets the old design with the findings; only what is needed changes.

Same idea in testing

The failure output goes to the Development or the Test Agent.

The code does the routing,
not the model.

This is how work goes back from one agent to another. The code reads the verdict line in the Review Agent's report. On REVISE it calls the Design Agent again with the findings. There are at most two rounds, otherwise it could loop forever. The repair loop in testing works the same way.
