How it works

The agents
check each other

Review loop

  1. The Review Agent compares the design with the requirements.
  2. The report contains a verdict line: VERDICT: APPROVE or REVISE.
  3. On REVISE the Design Agent fixes the findings.

at most 2 rounds, then it moves on

Test / repair loop

  1. The tests really run.
  2. The failure output goes back to the right agent.
  3. A repair that breaks passing tests is rolled back.
  4. More passing tests each attempt earn extra attempts.

2 repairs by default + 2 extra attempts

We do not expect the right result in one pass. The Review Agent can reject the design; then the Design Agent fixes it. When tests fail, their output is given back to an agent. An important detail: if a repair breaks tests that passed before, we roll it back, so we never lose a good state.
