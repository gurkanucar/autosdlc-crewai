class SDLCFlow(Flow):
    @start()
    def plan(self):
        return session.execute("planning", ...)

    @listen(plan)
    def analyse(self, _previous):
        return session.execute("analysis", ...)

    @listen(analyse)
    def design(self, _previous): ...

    # review → develop → test → deploy → maintain

runner.py · stage inputs

# which documents does each agent read?
STAGE_INPUTS = {
  "analysis":    ("planning",),
  "design":      ("analysis", "planning"),
  "review":      ("design", "analysis"),
  "development": ("design", "analysis",
                  "review"),
  "testing":     ("analysis", "design"),
}

@listen: when a stage ends, the next one starts. Earlier documents go into the prompt's $context.

AutoSDLC · SDLC with AI agents07 / 24

The agents do not talk to each other directly. The Flow starts the next stage when one finishes. STAGE_INPUTS decides what an agent knows: for example the Development Agent sees the design, the requirements and the review report. The user's answers and decisions are added to every prompt's context too.
