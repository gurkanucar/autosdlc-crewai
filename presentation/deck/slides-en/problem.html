Problem

Why is “write me an app”
not enough for an LLM?

User

Write me an event registration app.

Model

Here are 400 lines of code! Good luck.

No requirements

We cannot measure whether it did the right thing.

No tests

Nobody knows whether the code works.

No documents

Architecture decisions get lost in the chat.

Hard to change

A small request makes it rewrite everything.

Real projects have a process around the code: the SDLC.

AutoSDLC · SDLC with AI agents02 / 24

Generating code from a single prompt is nice for a demo, but without requirements, tests and documents we cannot tell whether it is right. When we ask for a change, the model usually rewrites everything. The idea: apply the SDLC stages we learned in software engineering to agents.
