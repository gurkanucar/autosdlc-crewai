Neden?

JavaScript'te /i bayrağı Türkçe “İ” (U+0130) harfini “i” ile eşlemiyor.

İkinci tuzak

Python'da re.I eşliyor. Kontrolümüzü Python ile yazınca hata görünmedi.

Çözüm

Build check JavaScript davranışını taklit edip test koşmadan önce uyarıyor.
