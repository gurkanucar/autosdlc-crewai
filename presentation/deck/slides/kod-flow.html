# her agent hangi dokümanları okur?
STAGE_INPUTS = {
  "analysis":    ("planning",),
  "design":      ("analysis", "planning"),
  "review":      ("design", "analysis"),
  "development": ("design", "analysis",
                  "review"),
  "testing":     ("analysis", "design"),
}

@listen: bir aşama bitince sıradaki başlar. Önceki dokümanlar prompt'taki $context değişkenine girer.
