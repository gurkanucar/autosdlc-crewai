etkinlik kayıt uygulaması

backend

Express 5 + TypeORM

PostgreSQL, JWT ile giriş, zod doğrulama, kapak resmi yükleme, user / organizer / admin rolleri.

React 18 + Ant Design

Vite ile build, Türkçe arayüz, etkinlik kartları, “Doldu” ve “Kayıtlısın” etiketleri.

API ve UI testleri. Docker Compose ile Dokploy'a deploy edildi, demo verisiyle canlıda.
